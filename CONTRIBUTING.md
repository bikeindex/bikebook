# Contributing to BikeBook

We welcome corrections and new models: open a pull request.

## Contributor License Agreement

Anyone contributing to [bikeindex/bikebook](https://github.com/bikeindex/bikebook) **must read & sign our [Contributor License Agreement](https://cla-assistant.io/bikeindex/bikebook)**. We can't merge a pull request until its author has signed.

The first time you open a pull request, the CLA Assistant bot comments on it with a link to sign it with your GitHub account. You sign once, and again only if the agreement changes.

## Making a change

CI checks every data file on each pull request.

`README.markdown` describes how the files are laid out and what is up.
