# Contributing to BikeBook

We welcome corrections and new models: open a pull request.

## Contributor License Agreement

Anyone contributing to [bikeindex/bikebook](https://github.com/bikeindex/bikebook) **must read & sign our [Contributor License Agreement](CLA.md)**. We can't merge a pull request until its author has signed.

The first time you open a pull request, the CLA Assistant bot comments on it with a link to [sign the agreement](https://cla-assistant.io/bikeindex/bikebook) with your GitHub account. You only sign once; it covers all your later pull requests.

## Making a change

Each data file has to pass the checks `cargo test` runs: `AGENTS.md` describes how the files are laid out and what's checked. CI runs them on every pull request.
